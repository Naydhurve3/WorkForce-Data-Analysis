# WorkForce Data Analysis — Research Paper Assets

This folder contains all assets needed to write and submit a research paper
based on the WorkForce Data Analysis v2.0 project.

## Contents

| Folder | Description |
|--------|-------------|
| `01_findings/` | Extracted data as CSVs + TXTs (interaction rankings, model metrics, deep dives, feature importance, etc.) |
| `02_figures_curated/` | 11 publication-ready figures selected from the 60 generated by the pipeline |
| `03_formulations/` | Mathematical formulas, model configurations, feature lists, and methodology documentation |
| `04_paper_blueprint/` | Paper draft sections (abstract, introduction, methodology, results, discussion, conclusion) + references |
| `05_future_goal/` | v3.0 blueprint for capability-to-role matching + interview bias detection + working prototypes |
| `06_appendices/` | Reproducibility guide, ethical statement, data dictionary |

## Paper Summary

**Title**: Systematic Interaction Mining in Workforce Analytics: An Exhaustive
Multi-Outcome, Multi-Model Empirical Evaluation

**Core contribution**: A systematic framework for exhaustive pairwise
interaction mining in workforce data, including a novel Interaction Impact
Score, multi-model multi-outcome ablation analysis, and actionable deep-dive
simulations.

**Data**: 3,000 synthetic employee records, 53 features, 5 outcomes,
1,755 interaction tests.

**Models**: Logistic Regression, Random Forest, XGBoost — compared with
and without interaction features.

**Key finding**: Interaction features provide ~1-3% accuracy improvement.
Top discovery: JobFamily x DepartmentType → PayZone (impact = 181.3).
